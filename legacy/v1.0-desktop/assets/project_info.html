Project Information

This Project was developed by Podugu Bala Veera Venkata Sunil et al as a part of Cyber Security Internship.
This project is designed for finding the open ports and closed ports which are presented in the websites, simulating offensive and defensive postures for real-world cyber defense, and mitigating risks of cyber fraud.
Project NameSHADOW PORTX - Offensive & Defensive Port Scanner
Project DescriptionShadowPortX is a powerful and easy-to-use port scanning tool developed as part of a Cyber Security Internship at Supraja Technologies. This tool helps users scan network ports to find open services on target machines. It is designed for both offensive (ethical hacking) and defensive (security testing) purposes.
Key Features: ✅ Scan TCP ports within custom ranges ⚡ Fast scanning using multi-threading 🧠 Basic service detection and banner grabbing 📁 Automatic export of scan results as PDF and JSON 🛠️ Settings tab to customize ports, timeout, threads, and theme 🌙 Dark mode support and smooth, modern GUI
