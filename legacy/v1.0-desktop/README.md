# ⚡ ShadowPortX – Hacker's Port Scanner

ShadowPortX is a powerful GUI-based port scanner designed for penetration testers, ethical hackers, and network administrators. It offers multiple scan modes, export options, threaded scanning, and a modern PyQt6 interface.

---

## 🚀 Features

- ✅ **TCP / UDP / Stealth / Version Scans**
- 📜 **Auto export to PDF / JSON**
- 🎯 **Target intelligence lookup (whois, DNS, etc.)**
- ⚙️ **Customizable settings panel**
- ⚡ **Multi-threaded scanning**
- 🖥️ **Cross-platform PyQt6 GUI**
